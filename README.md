# Presenter · Actualizaciones para Windows

Paquetes de actualización de Presenter, una aplicación de escritorio para proyectar canciones y pasajes bíblicos.

## Actualizar

Desde Presenter 1.2.0: pulsa **Buscar actualización**, descarga la versión disponible y elige **Actualizar y reiniciar**. Cierra antes la salida al proyector.

Si todavía utilizas la 1.1.0, descarga `Presenter-1.3.0-Windows-x64-Update.exe` desde [Releases](https://github.com/kevind700/presenter-releases/releases), cierra Presenter y ejecuta ese archivo una sola vez. Las siguientes actualizaciones se solicitan desde la aplicación.

Estos paquetes requieren una instalación existente de Presenter para Windows x64. Conservan canciones, Biblia, fondos y ajustes locales. Incluyen la aplicación y Java; no contienen la biblioteca personal, letras, texto bíblico ni videos de los usuarios.

## Canal de versiones

`https://github.com/kevind700/presenter-releases/releases/latest/download/latest.json`

El índice está firmado con Ed25519. Presenter verifica la firma, el tamaño y el SHA-256 antes de ejecutar una actualización. Esta firma del índice no equivale a una firma Authenticode del EXE.

La instalación, el inicio, la actualización y el reinicio se validan en Windows Server 2022 mediante GitHub Actions, incluyendo recuperación ante un runtime bloqueado y conservación de la biblioteca. Las pantallas físicas y la red Wi-Fi deben verificarse en el lugar de uso.
